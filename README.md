# lw6 — DateTime и исключения

Два независимых задания с классами, валидацией дат и `InvalidArgumentException`.

## Задания

| Каталог | Класс | Тема |
|---------|-------|------|
| `task1_v2/` | `Delivery` | Доставка: опоздание, задержка в минутах |
| `task2_v2/` | `CarRental` | Аренда авто: плановые/фактические дни, стоимость |

## Установка и запуск

```bash
cd task1_v2
composer install
php index.php

cd ../task2_v2
composer install
php index.php
```

Формат даты в консоли: `YYYY-MM-DD HH:MM`.
